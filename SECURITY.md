# Security policy

Report a vulnerability through
[GitHub private vulnerability reporting](https://github.com/andrewbakercloudscale/sg-tightener/security/advisories/new)
rather than a public issue. Expect an acknowledgement within a week.

In scope: anything that could make the tools open access that the plan did not
show, revoke access that `revert` cannot restore, or leak credentials.

Files the tools generate (`approved.json`, `plan.json`, manifests, reports)
describe your network. Do not attach real ones to issues; redact addresses and
account ids first.
